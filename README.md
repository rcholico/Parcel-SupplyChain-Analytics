# 📦 US Parcel Network Analytics

**Data Science & Optimization Model for Parcel & Freight Network Analysis**

An end-to-end data analytics and predictive modeling project leveraging parcel shipment and operational datasets to analyze transit efficiencies, cost-per-package metrics, and delivery network performance.

---

## 🎯 Project Overview
Logistics networks require continuous evaluation of carrier SLAs, zone pricing structure, and delivery density. This project analyzes raw parcel operational data in Python to identify cost bottlenecks, delivery route inefficiencies, and volume distribution trends across geographic zones.

---

## 🔑 Key Features & Analysis
* **Freight Cost & Rate Matrix Modeling:** Evaluated dimensional weight (DIM) vs. actual weight impacts on carrier zone billing.
* **Transit & SLA Performance Analytics:** Modeled on-time delivery percentages and transit delays across Ground, 2nd Day Air, and Next Day Air service levels.
* **Volume & Density Heatmapping:** Mapped regional shipment density to highlight high-cost, low-density delivery clusters.

---

## 🛠️ Tech Stack
* **Environment:** Google Colab / Python
* **Data Science Tools:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn
* **Domain:** Carrier Contract Sourcing, Parcel Analytics, Supply Chain Optimization
